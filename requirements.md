Текстовый редактор Ranobi — прототип
1. Назначение
Создать личный кастомизируемый текстовый редактор для написания ранобэ.

Прототип предназначен для проверки базового сценария написания и локального хранения текста.

2. Пользовательские требования
Первая версия должна позволять пользователю:

создавать текстовый документ;
редактировать текст;
отменять и повторять действия (Undo/Redo);
видеть количество символов с пробелами и без пробелов;
сохранять документ в .txt локально;
загружать .txt локально;
автоматически сохранять текущий черновик локально;
восстанавливать черновик после перезагрузки страницы.

Редактор должен:

работать без подключения к серверу и интернету;
не отправлять содержимое документов третьим сторонам.

3. Функциональные требования

Редактирование

Основная область редактирования реализована через div[contenteditable].
Пользователь может вводить и удалять текст.
Ctrl+Z отменяет последнее действие редактирования.
Ctrl+Y повторяет отменённое действие.
Сохранение в файл
Кнопка «Сохранить» сохраняет текущий текст в .txt.
Для создания файла используется Blob.
Скачивание выполняется средствами браузера через URL.createObjectURL().
Приложение не требует прямого доступа к файловой системе пользователя.

Загрузка файла

Кнопка «Загрузить» открывает выбор локального файла.
Для выбора файла используется <input type="file">.
Поддерживается формат .txt.
Содержимое файла читается на стороне клиента через File.text() или эквивалентный API.
Загруженный текст помещается в область редактирования.
Автосохранение
После изменения текста текущий черновик сохраняется в локальном хранилище браузера.
На первом этапе для хранения используется localStorage.
При открытии приложения проверяется наличие сохранённого черновика.
При наличии черновика он восстанавливается в редакторе.

Счётчик

В интерфейсе отображается количество символов с пробелами.
В интерфейсе отображается количество символов без пробелов.
Счётчик располагается в footer.
footer закреплён в нижней части окна (position: fixed).
